# portfolio-v2

The second version of my personal portfolio: a single-page developer portfolio built with React, TypeScript, Material-UI and Overmind. Fork it, change one file with your details, and put your own portfolio on GitHub Pages for free.

![portfolio-v2 preview](https://user-images.githubusercontent.com/6418354/108698254-2256ee80-752e-11eb-8767-aeb5a4f86536.gif)

**Live demo:** https://p32929.github.io/portfolio-v2/

## Features

1. **All your data in one file:** your name, links, works and skills live in `src/Others/GlobalVars.ts`. Nothing else to touch.
2. **Pick your colours:** a built-in colour picker lets visitors change the page colours on the fly.
3. **Clean layout:** your profile stays on the left, and About, Skills, Works and Contact open on the right.
4. **Simple state:** small, typed state with Overmind instead of a lot of Redux code.
5. **Free hosting:** it goes live on GitHub Pages with two commands.

## Prerequisites

You need `NodeJS` and `NPM` installed. Grab them here: https://nodejs.org/en/download/

## Run it locally

```bash
git clone https://github.com/p32929/portfolio-v2.git
cd portfolio-v2
npm install
npm start
```

## Create your own portfolio

1. Fork the repository (recommended).
2. Rename the fork to `your-github-username.github.io` in its settings
3. `git clone YOUR-REPOSITORY-URL`
4. Edit `src/Others/GlobalVars.ts` — your data, your flavours
5. `npm run predeploy`
6. `npm run deploy`
7. In your repository settings, point GitHub Pages at the `master` branch

That's it. Your portfolio is live at `https://your-github-username.github.io/`. GitHub Pages usually takes 3 to 5 minutes to show the change. If it still doesn't show, run steps 5 and 6 again.

## FAQ

1. **Can I use it for a personal or commercial portfolio?** Yes. Please fork it, and keep the fork icon at the top right and the link it opens, so others can find this repo too.
2. **Can I share your portfolio with my friends?** Of course, thank you!
3. **Can I ask you for help if I get stuck making my own?** Yes. Open an issue and I will help.
